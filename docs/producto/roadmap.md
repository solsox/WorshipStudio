# Roadmap

## Fase 0

- Inicializar el fork.
- Definir identidad.
- Aislar configuración.
- Preparar estructura para importar OBS.

## Fase 1

- Arrancar compilación en macOS Apple Silicon.
- Verificar apertura de la app.
- Mantener features base de OBS.
- Scaffold inicial de paneles nativos de Himnario y Biblia.

## Fase 2

- Integrar panel nativo de Himnario.
- Integrar panel nativo de Biblia.
- Integrar visor PDF.
- Añadir biblioteca multimedia unificada.

## Fase 3

- Añadir planificador de servicio.
- Añadir macros.
- Añadir control remoto.
- Añadir modo browser limpio.

## Fase 4

- Mejoras de rendimiento.
- Pulido visual.
- IA como módulo futuro opcional.
